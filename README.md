# morphagene-mods-navigator

travelers guide for manipulating wormholes: a one-page reference for **morphagene mods**, briskcat's unofficial add-ons to the make noise morphagene mg204 firmware. shift gestures, tape mode, srr / warble, octave lock, jitter, turing mode, the remembered input gain, options.txt keys, install steps and use-at-your-own-risk notes, with diagrams.

the mods are by [briskcat / morphagene-mods](https://briskcat.github.io/morphagene-mods/) (mit). this guide contains no firmware. build your own copy with the project's [web builder](https://briskcat.github.io/morphagene-mods/), and use it at your own risk.

live page: https://mellotom.github.io/morphagene-mods-navigator/
part of the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

not affiliated with make noise or briskcat.
