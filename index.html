the mods

mm_01 · by briskcat
what it is
new features added to your own copy of the official mg204 firmware: shift gestures, a remembered input gain, sd-card updates
made by
briskcat / morphagene-mods · mit licence · an unofficial community project
not included
no make noise firmware is shared: you download mg204.wav yourself and the builder patches it on your computer
switch off
every feature has an off setting in options.txt, so one build covers every combination

03

tape mode

mm_03 · [ shift ]+turn [ s.o.s. ]
switch on
the first [ shift ]+turn [ s.o.s. ] after power-up · until then s.o.s. is stock
overdub a splice
a virtual tape head writes inside the slide / gene-size window at the vari-speed rate: backwards in reverse, paused at stop
[ shift ]+turn [ s.o.s. ]
how much of the old recording stays each pass (tape feedback) · 100% with silence changes nothing
[ s.o.s. ] alone
still sets what you hear
morph cap
morph is held to 0.3 while dubbing, to stay inside the cpu budget
[ shift ]+turn [ s.o.s. ]
◆ tape 0
classic tla feedback: records input + playback, the gesture sets how much playback goes back in
morph cap
◆ mcap
1–9 = 0.1–0.9 · 0 = none (above 5 can glitch)
04

srr · warble · lock

mm_04
[ shift ]+turn [ morph ]
sample-rate reduction on the gene playback: fully left = off, right = more (down to 200 hz)
[ shift ]+turn [ morph ]
◆ fxsl 2 / 0
2 = tape warble: wow & flutter on playback speed, up to ~1.4 semitones, lighter on cpu · 0 = off
builds up
the input is untouched, so with feedback or tla the effect grows pass by pass · resets at power-up
[ shift ]+turn [ vari-speed ]
octave lock: snaps to exact rates (fig.01) and stays locked after you let go
unlock
turn vari-speed about half an octave away
[ shift ]+turn [ slide ]
jitter: each new gene starts at a random offset around slide · left = off, right = wider
__fig.02 : the tape headtape mode, overdubbing
05

turing mode

mm_05 · ◆ sldm 1
1
set sldm 1 in options.txt, power on · gene-size ~1:00 · morph low = melody, higher = chords
2
lock: hold [ shift ], turn [ organize ] fully left · the pattern repeats
3
mutate: [ shift ]+turn [ organize ] up from the left · steps sometimes change
4
new pattern: [ shift ]+turn [ organize ] fully right, then back fully left
[ shift ]+turn [ gene-size ]
genes per step: 1 · 2 · 3 · 4 · 6 · 8 · 12 · 16
[ shift ]+turn [ slide ]
spread: start jitter, repeated by each step when locked
loop length
◆ tlen
1–16 steps (default 8)
root chance
◆ root
% of steps that play the root pitch · 100 = no pitch changes
pitches
from the stock chord ratios mcr1–mcr3 · no LED feedback

use at your own risk

mm_08 · read first
unofficial
a community project: not made, endorsed or supported by make noise · don’t ask them for help with it
no warranty
mit licence, provided “as is” · you are changing the firmware in your module
before you start
copy your sd card (reels + options.txt) somewhere safe
mg204 only
the builder refuses any other firmware file
don’t share builds
the files you make contain make noise’s firmware · share the project link instead
cpu
high morph + short genes can glitch (so can stock) · try warble, or a lower mcap
cv on a gesture knob
can count as a turn while shift is held: a shift tap may not change splice
power loss
during an options.txt rewrite can reset your settings to default
